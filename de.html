So verwenden Sie den Checker

Entwickelt für Indie-Entwickler und Blogger, die eine ehrliche Einschätzung wollen.

  1. Geben Sie Ihre Seitenaufrufe ein. Verwenden Sie die Metrik "Seitenaufrufe" (nicht Sitzungen) aus Ihrem Analyse-Tool.
  2. Wählen Sie den passenden RPM. RPM ist das, was Sie pro 1000 Impressionen verdienen. Wählen Sie die hohe Stufe für US-Finanzen, die niedrige für weltweite Unterhaltung.
  3. Klicken Sie auf Prüfen. Sie sehen eine Traffic-Stufe mit realen Beispielen und eine Schätzung in USD und CNY.
  4. Lesen Sie die Warnung. Bei geringem Engagement werden Anzeigen unten auf der Seite nie gesehen. Es ist eine optimistische Obergrenze.

Funktionen

  • Realistische Benchmarks. Jede Stufe enthält Beispiele echter Websites.
  • AdSense-konforme Berechnung. Verwendet Seitenaufrufe und regionale Unterschiede.
  • Datenschutz first. Keine Daten werden an Server gesendet.
  • Auf jedem Gerät. Funktioniert auf Handy, Tablet und PC.
  • Kostenlos & unbegrenzt. Ohne Anmeldung.
