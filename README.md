# 🌐 Website Traffic Level & AdSense Estimator

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Vanilla JS](https://img.shields.io/badge/JavaScript-Vanilla-yellow.svg)
![No Dependencies](https://img.shields.io/badge/dependencies-0-success.svg)

A lightweight, privacy-first, and fully client-side web tool that helps indie developers, bloggers, and site owners evaluate their website's traffic level against real-world benchmarks and estimate potential Google AdSense revenue.

## ✨ Features

- **📊 Real-world Benchmarks:** Don't just look at numbers. Compare your daily pageviews (PV) against real website examples (from hobby blogs to top-tier sites like Canva).
- **💰 Official AdSense Formula:** Estimates revenue using the official Google AdSense RPM (Revenue Per Mille) calculation logic: `(Pageviews / 1000) × RPM`.
- **🌍 Regional RPM Tiers:** Recognizes the massive monetization gap between different niches. Choose from high-value English (Finance/B2B), mid-value (Tech), general English, or Asian/Entertainment traffic.
- **🌐 Multi-language Support:** Built-in support for English, Chinese, French, and German with proper `hreflang` SEO tags.
- **🔒 Privacy-First:** Runs entirely in the browser. No database, no backend, no API calls. Your traffic data never leaves your device.
- **⚡ Zero Dependencies:** Built with pure HTML, CSS, and Vanilla JavaScript. No React, no Vue, no jQuery.

## 🚀 How to Use

Since this is a static web tool, you can run it in two ways:

1. **Local:** Simply download the `index.html` file and double-click it to open it in any modern browser.
2. **Self-Hosted:** Deploy the folder to any static hosting service (GitHub Pages, Vercel, Netlify, Cloudflare Pages).
